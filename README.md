## 299、449、699三个价位别混着看

搜补货的人经常被三个数字绕晕。299元/年是512MB内存、10GB硬盘、500GB流量的小配置，三个机房都有这个起步档。449元/年对应的是768MB或1GB内存的中间档，德国那款A2 mini是1GB/15GB/800GB。699元/年是1GB内存、20GB硬盘、1.2TB流量的年付特惠，德国和美国都有官方公告确认。

把299元档的配置当成449元档来比，会得出“1G内存年付299”的错误印象，下单时会发现购物车里根本不是那个价。以购物车页的套餐名和配置为准，价格对不上就说明你看的是另一款。

## 下单前必须知道的五条官方政策

2026年5月15日官方频道发过一条长公告，把售后规则一次讲清了。前排推广文大多只写“建议先确认退款政策”，实际规则比那句提醒硬得多。

1. **所有产品都没有退款政策。** 开通后不满意、线路不合预期、IP 不合要求，都不退。降低沉没成本的办法只有一个：先买月付或季付，跑一两周再决定要不要上年付。
2. **所有产品均未保证是原生 IP。** 对 IP 归属地有要求的业务不要买。第三方测评里“德国原生 IP、可解锁 Netflix”的说法和官方口径冲突，以官方为准。
3. **IP 被墙的换法**：充值30元到账户余额，提交工单让客服换。刚购买就被墙的，24小时内提交工单可以免费换。但美国、德国的换 IP 请求从2026年6月起暂停受理，英国不受影响。
4. **流量用完只能等账单日次日重置**，不能提前重置，也不能单独买流量包。
5. **月付想改季付或年付**，把对应金额充值到余额，提交工单续一个季度或一年。不换机器、不换 IP，也不能补差价改成更贵的套餐。

工单响应方面，官方承诺非节假日工作时间尽量24小时内回复，找不到人可以用频道左下角的私信按钮。它不是7×24秒回，急事别指望即时处理。

## 德国、美国、英国怎么选

按业务面向地区定，不要只看价格。

做欧洲市场，选德国法兰克福。法兰克福是欧洲主要互联网交换节点，到欧洲各国的链路质量稳定，适合欧洲电商、广告投放、面向欧洲站点的采集、海外 SaaS 部署。德国也是这三条线里补货最频繁、套餐最全的，从1GB小配置到8核16G不限流量都能找到。

主要服务国内用户、或者业务面向美洲，选美国圣何塞。三个机房里它的起步价最低，套餐结构简单，国内访问延迟比欧洲节点低。

做英国本地业务，或者想给德国节点做备份，选英国伦敦。英国 CN2 GIA 的供应商本来就少，299元/年的起步档不算贵。把两个不同机房的机器分开跑，比在同一个机房买两台更能扛住单点故障。

三条线都是三网回程 CN2 GIA，电信和联通去程走 CN2 GIA。移动去程走 CMIN2 的说法只在第三方测评里出现，官方公告没有提，别把它当成合同条款。

## 小厂风险要有具体预期

2026年9月5日，英国 CN2 一台宿主机硬盘故障，官方把受影响实例重建到其他宿主机，并延长1个月可用时长。2025年1月英国 CN2 也有一台宿主机失联，约60名用户受影响。2024年4月上游 IP 提供商出问题，38段 IP 短暂不可用。

这些故障的处理速度和补偿方式算是有交代，但也说明单台机器不能当唯一副本。重要数据定期备份到别处，关键业务拆到两个不同机房，比研究哪家永远不会出故障更实际。
